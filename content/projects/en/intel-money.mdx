## Introduction

**Intel Money** is my Bachelor's Capstone Graduation Project at Hanoi University of Science and Technology (HUST).  
The solution empowers everyday individuals to take control of their **personal finances**, enabling income and expense tracking, recurring budget planning, category breakdowns, and loan/debt monitoring.

The system encompasses a **cross-platform mobile app (Flutter)** and a **backend API (NestJS)**, containerized with Docker and continuously deployed via CI/CD. The application was approved and published for beta testing on the **Google Play Store**.

## My Role & Responsibilities

- Sole developer handling end-to-end architecture: mobile app (Flutter) and backend services (NestJS).  
- Database schema design (MySQL) and caching layer (Redis).  
- Built automated AI natural-language transaction parsing and receipt optical character recognition (OCR).  
- Configured automated CI/CD pipeline using **GitHub Actions, Docker Hub, and cloud VPS**.  
- Prepared release artifacts, managed keystores, and handled the **Google Play Store submission process**.

## Technical Highlights

- **Mobile Client:** Flutter, Provider/Riverpod state management, responsive UI.  
- **Backend Architecture:** NestJS, TypeScript, JWT auth, Swagger documentation.  
- **Database & Cache:** MySQL 8 with relational integrity, Redis caching for fast lookup.  
- **DevOps & Infrastructure:** Docker containerization, GitHub Actions CI/CD to remote VPS.

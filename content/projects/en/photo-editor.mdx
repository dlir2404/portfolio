## Introduction

Lightweight Photo Editor is an online image editing utility providing practical, rapid editing tools directly inside the web browser without demanding heavy desktop software.  
This served as my **onboarding starter project at True Platform**, designed to evaluate and integrate `Fabric.js` into the company's proprietary front-end web framework.

## My Role & Responsibilities

- Designed the core state management and canvas interaction architecture.  
- Integrated Fabric.js with native HTML5 Canvas for fast rendering performance.  
- Engineered user experience features: 20-step undo/redo stack, object layer locking, and custom transforms.  
- Authored the user interface strictly using **HTML, CSS, and Vanilla JS/jQuery** without relying on third-party UI component libraries.

## Technical Implementation

- **Framework:** In-house proprietary PHP framework, Vanilla JavaScript, jQuery.  
- **Canvas Rendering Engine:** Fabric.js on top of HTML5 Canvas.  
- **Styling:** Custom CSS without heavy external CSS frameworks.

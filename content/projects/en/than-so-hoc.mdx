## Overview

A professional online numerology portal developed to help users discover personal strengths, life trajectories, and compatibility through mathematical calculations. The project blends historical numerological systems with modern web technologies to deliver an accessible, engaging digital reading experience.

## Key Features

- **Core Analysis Engine**: Generates comprehensive profiles based on full legal name, common nickname, and Gregorian birthdate.
- **Detailed Numerology Reports**: Calculates and illustrates over 20 distinct metrics including:
  - Life Path Number (Con số chủ đạo)
  - Birth Day Chart & Expression Numbers
  - Pythagorean Pinnacle Pyramids
  - Strength & Personal Year cycles
- **Advanced Features**:
  - Relationship and marriage compatibility matching.
  - Feng Shui / lucky phone number recommendation.
  - Historical lookup archive for registered accounts.
- **Account & Subscription Tier**:
  - User registration, login, and profile management.
  - Free preview report vs. comprehensive VIP tier.
  - Integrated online banking gateway for instant access unlocking.

## Technical Implementation

- **Frontend**: Next.js App Router for server-rendered, SEO-optimized landing pages and responsive user dashboards.
- **Backend**: NestJS RESTful API handling complex numerological matrix calculations and reporting pipelines.
- **Database**: Relational database storage for user profiles, transaction logs, and generated numerology artifacts.
- **Project Coordination**: Agile sprint management and backlog tracking conducted via Trello within a 4-person engineering team.

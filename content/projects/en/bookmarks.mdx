## Introduction

**Bookmarks App** is a versatile information storage and organization application that allows users to save both external web links and internal system resources.  
Beyond standard bookmarking, the platform provides rich collaboration features (sharing, commenting, activity history) and embeds AI capabilities to analyze and summarize saved content.

## My Role & Responsibilities

- Designed and engineered the end-to-end bookmarking module across both backend and frontend.  
- Integrated an intelligent link crawler to scrape Open Graph / meta tags for live link previews.  
- Architected the categorization system using flexible **lists and tags**.  
- Integrated AI services for automatic link parsing and semantic summarization.

## Key Features

### 1. Web Link Bookmarks
- Save any external web address with a single click.  
- Automatically extracts **Open Graph & meta tags** to render rich visual previews (title, summary, thumbnail).  
- AI-powered enhancements:  
  - **Content Extraction**: Strips clutter to retrieve the main article body.  
  - **Summarization**: Generates concise bulleted summaries.  
  - **Auto-tagging**: Suggests relevant tags for effortless organization.

### 3. Collaboration & Interactivity
Each bookmark (whether external URL or internal record) supports:  
- **Sharing**: Granular permissions to share with teammates.  
- **Comments**: Inline discussions and threaded exchanges.  
- **Notes**: Seamless integration with the platform's native note-taking module.  
- **Activity Logs**: Full audit trail of updates and interactions.

## Technical Stack

- **Internal Framework:** PHP backend, Vanilla JS / jQuery frontend.  
- **Crawler:** Asynchronous metadata and Open Graph scraper.  
- **AI Engine:** Content extraction, summarization, and auto-tagging models.  
- **Platform Modules:** Deeply integrated with internal Notes & Activity Logging services.

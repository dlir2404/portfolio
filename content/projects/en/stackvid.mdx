## Introduction

In short-form video commerce (TikTok Shop and affiliate marketing), sellers need a steady supply of product videos, but producing each one requires presenters, a studio, and editing time.

**StackVid** automates this production. Starting from a reference video of a product, the **T2T (Video-to-Video) AI pipeline** generates a new video with a different presenter, a new setting, and a new script, while keeping **the product itself accurate** to what buyers will receive. The platform then schedules the finished video for publishing with the TikTok Shop product link attached.

## Product Workflow

### 1. Reference Video Intake
- **Source channels:** The seller selects channels to follow, and the platform indexes their new videos automatically.
- **Product video detection:** Videos that feature a TikTok Shop product link are separated from general posts, so that only product content enters the pipeline.
- **Input extraction:** For each video, the platform collects engagement metrics and the audio transcript (WebVTT), which serve as input for script generation.

### 2. Product-Accurate Generation (Master Anchor)
- **New presenter and setting:** Each video is generated with an assigned digital persona in a clean studio setting.
- **Strict product constraint:** The AI identifies the product and locks its appearance in the generation prompt (for example, *"washed blue denim jacket, regular fit, metal buttons, chest flap pockets; keep product unchanged"*). Fabric, color, buttons, and pockets stay true to the item that buyers actually receive.

### 3. Script Generation and Lip-Sync Pacing
- **Five-segment sales structure:** The script follows a direct-response structure (`#0 HOOK → #1 FEATURE → #2 FEATURE → #3 BENEFIT → #4 CTA`) and is written fresh for the product's key benefits.
- **Pacing control:** Each segment is limited to **25–36 words**, matching the length of a 10-second clip (240 frames at 24 fps), so that the generated voice lines up with the presenter's lip movements.

### 4. Quality Scoring and Final Assembly
- **Automated quality checks:** Every rendered segment is scored for face consistency and product consistency before it is accepted.
- **Assembly:** The completed segments are joined into a single 9:16 vertical video with a mixed Vietnamese voice track.

### 5. Scheduled Publishing with Product Links
- **Watch mode:** When enabled, new videos from the selected source channels enter the processing queue automatically.
- **Publishing:** Finished videos are published within a configured time window (`08:00 – 22:30`) to the seller's own channel, with the TikTok Shop product link attached.

## Engineering Highlights

- **NestJS monorepo with gRPC microservices:** The public API gateway is decoupled from compute-heavy workers through gRPC. Services include the API gateway, the TikTok integration service, the flow service and workers, a Rust media engine, and a headless runner.
- **Parallel chunk rendering:** Each source video is cut into 10-second segments, and every segment becomes an independent job that can render on any available runner. A failed segment is retried on a different runner, and the final video is assembled once all segments are complete.
- **Two-phase credit engine:** Credits are reserved with an atomic SQL deduction before a job is sent to a third-party AI provider, then either committed on success or refunded in full on failure, which prevents double charging.
- **Automated payments:** Bank transfers via VietQR (SePay) are reconciled automatically and credited to the user's wallet within 5–15 seconds, without manual approval.
- **Selective builds and safe deploys:** The CI/CD pipeline compares each push with the last successful deployment and rebuilds only the services that changed. A migration gate runs every database migration against a throwaway database first, so a broken migration fails the build instead of the production rollout. Docker images build in parallel with layer caching, and production updates roll out through Docker Swarm.

## Supporting Features

- **Account management:** Each connected TikTok account runs in its own isolated session.
- **Streak Keeper:** Sends scheduled daily messages between the seller's own accounts to maintain engagement streaks, and skips the run when the accounts have already interacted that day.
